# Advanced Flutter CRUD Hackathon Template 🚀

This project is a starter template for a hackathon focused on advanced Flutter concepts:
- ✅ BLoC & Streams
- ✅ One-to-many: Company → Employees
- ✅ DataTable
- ✅ DropdownButton as Lookup
- ✅ Form Validation
- ✅ Localization / Internationalization
- ✅ OpenAPI Integration
- ✅ Tab-based CRUD for Companies and Employees

## Tasks for Participants
- Implement BLoC classes in `bloc/`
- Bind StreamBuilders to UI in both tabs
- Add validators in `validation/validators.dart`
- Integrate with a generated OpenAPI client in `api/openapi_client.dart`
- Handle localization in `l10n/` and `.arb` files

## Bonus 🎯
- Enable language switcher from UI
- Handle loading and error states gracefully
- Add tests!

Good luck & code fear free 💪🚀
